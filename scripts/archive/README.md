# Historical Scripts

This directory is retained for history only.

Do not use these scripts as the primary workflow for the current Smart City IDS stack.

Reasons:
- many of them predate the current active deployment path
- some refer to old manifests, old ports, or removed workflows
- they are useful as reference material, not as the default operator path

Use the active top-level scripts instead:
- `scripts/start-everything.sh`
- `scripts/deploy-code.sh`
- `scripts/pre-demo-check.sh`
- `scripts/demo-readiness.sh`
- `scripts/llm-manager.sh`
- `scripts/run-live-attacks.sh`
- `scripts/live-pipeline-log.sh`
- `scripts/tail-pipeline-pods.sh`

If a historical script is needed for investigation, review it manually before running it.
