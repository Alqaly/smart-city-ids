Practical status rule

                

                    
Green
Working now.

                    
Yellow / Degraded
Usable or partially available, but not fully healthy.

                    
Orange / Circuit open
Intentionally blocked after repeated failures.

                    
Red
Failing and needs remediation.

                

            


            

                

                    
Overview

                    
Live system posture: alert totals, IoT activity source metadata, pipeline throughput, detector/component health, and provider status.

                

                

                    
Alerts

                    
Grouped alert history with severity, detector, namespace/pod context, LLM outcome, and full prompt/response trace viewer.

                

                

                    
IoT Mesh

                    
Current IoT workloads and fleet telemetry. Device counts are source-qualified; degraded telemetry is explicitly labeled.

                

                

                    
LLM Control

                    
Provider health, failover chain, estimated token-cost usage, routing strategy, probe/test controls, and runtime event log.

                

                

                    
Automation

                    
Governance mode control (`manual`, `assisted`, `autonomous`) with pending queue, live counters, and action history. Full-autonomy profile is optional and explicit.

                

                

                    
K8s Cluster

                    
Cluster component availability and infrastructure context for services and detectors.

                

            


            

                
Status glossary

                

                    

                        Healthy / Operational

                        Live analysis or component path is working now.
                    

                    

                        Degraded / Cooldown

                        Still available, but temporarily limited after recent provider failures or partial-health warnings.
                    

                    

                        Circuit open

                        Circuit breaker blocked more traffic after repeated failures. Use diagnostics before retrying.
                    

                    

                        Auth failed / Unhealthy

                        Invalid credentials, provider errors, or component failures need remediation.
                    

                    

                        Analysis unverified

                        Configured, but no successful alert-analysis call has completed in this process yet.
                    

                    

                        Registered device

                        Logical inventory row only. This is not proof of active hardware without recent heartbeat or telemetry.
