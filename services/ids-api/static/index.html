Why Attack Simulation?
These buttons inject realistic security alerts into the IDS pipeline — the same JSON payloads that Falco and Suricata forwarders send in production. Each click triggers the full detection → LLM analysis → automated response chain so you can observe how the system classifies threats, assigns severity, and takes defensive action (pod isolation, service scaling) in real time.

How it works: Click a card → alert payload is POSTed to /api/alerts/internal → rate limiter + dedup check → LLM engine analyzes the alert → severity score assigned → automated K8s action if severity ≥ 6 → full result shown in the log below.

Falco alerts detect runtime threats (shell spawns, file reads, privilege escalation). Suricata alerts detect network threats (port scans, DDoS, exfiltration).
