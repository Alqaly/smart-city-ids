# Reference Documents

Academic support material for technical review, report writing, and evaluation preparation.  
For operational docs, see the parent [docs/INDEX.md](../INDEX.md).

Use it when you need:
- examiner and reviewer preparation
- capstone/report support
- evidence matrices
- time-bound validation snapshots
- metrics and audit notes

Do not start here if you are new to the project.

Start with:
1. `README.md` in the repository root
2. `docs/INDEX.md`
3. `docs/QUICKSTART.md`

## What belongs here

- examiner Q&A
- defense notes
- demo runbooks and cheat sheets
- academic/report support material
- evidence and metrics audits
- frozen evaluation inputs such as ground-truth CSV files

## What does not belong here

- the main current system architecture
- deployment instructions for normal users
- day-to-day operational runbooks
- active troubleshooting for the current stack

Those belong in the top-level `docs/` files.
