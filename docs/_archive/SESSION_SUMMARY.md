## 🔧 TECHNICAL DETAILS

### Problem → Solution Mapping

| Problem | Root Cause | Solution | File(s) |
|---------|-----------|----------|---------|
| PostgreSQL not deployed | Infrastructure designed but not deployed to K8s | Created postgres-deployment.yaml with auto-migrations | postgres-deployment.yaml |
| Database migrations never run | Migration file exists but no execution trigger | Mount migration file as ConfigMap, runs on pod init | postgres-deployment.yaml |
| Prometheus not scraping IDS API | IDS API didn't expose metrics port, ServiceMonitor misconfigured | Add port 8001, create proper ServiceMonitor | ids-api-FINAL.yaml, servicemonitor-ids-api.yaml |
| Grafana dashboard manual loading | Not using Grafana's provisioning feature | Implement provisioning with ConfigMaps | generate-grafana-provisioning.sh, grafana-provisioning-dashboards.yaml, grafana-deployment.yaml |
| Dashboard loading unreliable | Script-based approach, external API calls | Kubernetes-native provisioning (guaranteed) | generate-grafana-provisioning.sh, deploy.sh |

### Architecture Pattern Applied

```
Imperative (Scripts)          Declarative (Kubernetes Native)
─────────────────────────────────────────────────────────────

Manual script execution       Automatic on pod startup
API calls made externally     Configuration mounted as volumes
Variable success/failure      Guaranteed by Kubernetes
Data in pod storage          Persistent ConfigMaps/volumes
Restart loses data           Automatically re-applied
```

## 🔄 HOW TO USE

### First Time Deploy
```bash
./deploy.sh
# Automatically:
# 1. Generates grafana-provisioning-dashboards.yaml
# 2. Applies it to K8s
# 3. Deploys postgres with migrations
# 4. Deploys IDS API with metrics
# 5. Deploys Prometheus
# 6. Deploys Grafana with auto-provisioned dashboards
```

### Update a Dashboard
```bash
vim infrastructure/monitoring/grafana-dashboard-custom.json
./scripts/generate-grafana-provisioning.sh
kubectl apply -f k8s-manifests/grafana-provisioning-dashboards.yaml
kubectl rollout restart deployment grafana -n monitoring
```

### Verify Deployment
```bash
# Check all components
kubectl get pods -n smart-city
kubectl get pods -n monitoring

# Verify metrics
kubectl port-forward -n monitoring svc/prometheus 9090:9090
# Visit http://localhost:9090/targets → ids-api should be UP

# Verify dashboards
kubectl port-forward -n monitoring svc/grafana 3000:3000
# Visit http://localhost:3000 → 7 dashboards visible
```
