HOW TO USE
================================================================================

FIRST TIME DEPLOYMENT:
  ./deploy.sh
  
  What happens automatically:
  1. Generates grafana-provisioning-dashboards.yaml
  2. Applies ConfigMaps to K8s
  3. Deploys PostgreSQL with migrations
  4. Deploys IDS API (with metrics)
  5. Deploys Prometheus
  6. Deploys Grafana (dashboards auto-load)

VERIFY EVERYTHING WORKS:
  # Check pods running
  kubectl get pods -n smart-city
  kubectl get pods -n monitoring
  
  # Check Prometheus scraping
  kubectl port-forward -n monitoring svc/prometheus 9090:9090
  # Visit http://localhost:9090/targets
  # ids-api endpoint should show "UP"
  
  # Check Grafana dashboards
  kubectl port-forward -n monitoring svc/grafana 3000:3000
  # Visit http://localhost:3000
  # Login: admin / admin
  # All 7 dashboards should be visible (no import needed!)

UPDATE A DASHBOARD:
  vim infrastructure/monitoring/grafana-dashboard-custom.json
  ./scripts/generate-grafana-provisioning.sh
  kubectl apply -f k8s-manifests/grafana-provisioning-dashboards.yaml
  kubectl rollout restart deployment grafana -n monitoring
